## Setting and notes

- **Qwen3.8-27B oQ5 + MTP**: quantization oQ5 (Qwen/Qwen3.8-27B@1d4bf0f2ff, oq_convert level 5, MTP kept); speculative decoding mtp; sampling temperature 1.0, top_p 0.95, top_k 20
  - Converted 2026-10-21 by the qwen3.8-27b campaign (oMLX 0.7.1rc1 oQ, group 64, full-precision sensitivity, MTP head kept).
  - Read only: its files are hard links shared with the agent-benchmark session's models/chat copy.
- Thinking is off (`enable_thinking: false`, no `reasoning_effort`) in every request of both legs, except the M3 thinking cell of models with speculative decoding, which sends `enable_thinking: true` only, so each template renders its own default effort. Without speculative decoding the thinking cell would repeat the 16K decode rate and is not run.
- Text-only: every screenshot is replaced by its text equivalent of equal token size (Qwen3.8 tokenizer), for every model.
- M4 headline = sum of TTFT over the 21 steps + 21 x 100 / R, where R is the run's decode rate (completion tokens / decode time over steps with server usage). The raw total mixes byte-identical prefill with each model's own output length, so a terser model would win it regardless of speed. Cap hits count `finish_reason=length` and streams cut inside a tool call (`incomplete_tool_call`), which still count as latency samples.
- Decode tok/s counts each model's own tokens. M3's output is a JSON array, where token counts are about equal across tokenizers; seconds per 100 tokens are given for the same reason. Prompt sizes are Qwen3.8 tokens ("16K" = 16,000); every result records the server's own `prompt_tokens`.
- Memory: server footprint of the oMLX process tree (`footprint`, RSS fallback); the system delta is wired + compressed + file-backed memory against the pre-launch baseline. File-backed pages are the page cache: mmapped weights appear in the delta only if they were not already cached before the launch, so the delta is an indication, not a measure of mmapped memory.
- Cross-night band (old campaign): M1 and M3 up to ~20 %, M4 ~9 %. A ratio marked ≈ lies inside it and counts as no difference.
- Capability: solved = the checker passes within the 30-step budget (also after a wall timeout); runs excluded only for pipeline mismatches (model id, forwarded sampling or thinking). Anomalies (5xx, a reasoning leak with thinking off, a template fallback) are attributed to the model, never excluded, and counted per model; they do not change the checker's verdict.
- Protocol version(s): 1 (current: 1); harness epoch(s): 7582825160ad.
- Earlier measurements: the Qwen3.8-27B serving campaign (`../qwen3.8-27b_20261017-2258_benchmark`, 2026-10-17..22) is not comparable with these tables: it used image-mode M1/M4, temperature 0 for some rows, three M4 runs with whole-run exclusion of cut steps, and an older localmelo (`5c009a8-dirty`).
